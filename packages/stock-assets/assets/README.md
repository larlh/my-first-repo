Built-in stock media of Parlante. Everything here is generated by code — nothing is downloaded.

- `backgrounds/<id>.jpg` — 18 backgrounds, square 1920 px masters (with `fit: cover` one file
  fills 16:9, 9:16 and 1:1 canvases; the subject stays in the centre).
- `music/<id>.m4a` — 8 seamless music loops (AAC-LC 128 kbit/s, 48 kHz stereo, −16 LUFS).
  Loop the DECODED audio (WebAudio `loop`, ffmpeg `aloop`), not the file (`-stream_loop`).
- `manifest.json` — size, SHA-256 and dimensions of every file (checked by the package tests).
- `avatars/` — photorealistic stock avatars; owned by `services/avatar-engine` (see its README).

Do not edit by hand. Painters live in `src/generators/backgrounds.ts`, tracks in
`src/generators/music/tracks.ts`, ids and names in `src/catalog.ts`. To regenerate (needs ffmpeg):

    pnpm --filter @parlante/stock-assets generate          # all, or `-- <part of an id>`
    pnpm --filter @parlante/stock-assets generate:check    # regenerate in memory and compare
